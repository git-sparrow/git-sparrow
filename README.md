## Kavtsya

A multi-café loyalty platform for the Ukrainian market, built solo in my free time during
military service. The API is in production and the iOS build is in TestFlight; not yet in
the stores.

React Native and Expo client, Hono API on Node.js, PostgreSQL with raw SQL, and an
AI coffee-fortune feature using Claude. I build it with Claude Code and Codex as coding
agents; I review, test and document every change, and the repo has 20 architecture
decision records. Three of them:

- [Зернятко (loyalty bean) balance is a derived event ledger, not a mutable counter](https://github.com/git-sparrow/kavtsya/blob/main/docs/adr/0010-event-ledger-balance-derived.md)
- [Dynamic QR code — rotating signed token](https://github.com/git-sparrow/kavtsya/blob/main/docs/adr/0006-dynamic-qr-code.md)
- [Data fetching: one hand-rolled hook, not a query library](https://github.com/git-sparrow/kavtsya/blob/main/docs/adr/0016-hand-rolled-data-fetching.md)
